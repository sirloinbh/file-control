# file-control

파일 컨트롤 - 내 컴퓨터 속 파일의 이름 변경, 압축 해제, 이동, 삭제 등을 자동화하는 개인 도구

외부 패키지 없이 Node.js(22 이상)만으로 동작하는 명령줄 도구 `fctl`이다.
Windows에 기본으로 있는 `fc`(파일 비교) 명령과 겹치지 않도록 이름을 `fctl`로 정했다.

## 설치

```bash
npm link                     # 어느 폴더에서나 fctl 명령을 쓸 수 있게 등록
npm unlink -g file-control   # 등록 해제
```

설치하지 않고 `node bin/fctl.js <명령>`으로 실행해도 된다.

## 명령

| 명령 | 하는 일 |
| --- | --- |
| `fctl ls [폴더]` | 폴더 내용 보기 |
| `fctl mkdir <폴더>` | 폴더 만들기 (중간 폴더도 함께) |
| `fctl write <파일> [내용]` | 파일 만들기 (내용이 없으면 표준 입력에서 읽음) |
| `fctl append <파일> [내용]` | 파일 끝에 내용 추가 |
| `fctl cat <파일>` | 파일 내용 보기 |
| `fctl rename <경로> <새이름>` | 같은 폴더 안에서 이름 바꾸기 |
| `fctl mv <원본...> <대상>` | 옮기기 (대상이 있는 폴더면 그 안으로) |
| `fctl cp <원본...> <대상>` | 복사하기 |
| `fctl rm <경로...>` | 휴지통으로 보내기 |
| `fctl unzip <압축파일> [폴더]` | 압축 풀기 (기본: 압축파일 이름의 폴더) |
| `fctl zip <압축파일> <원본...>` | 압축하기 (`.zip`, `.tar.gz` 등 확장자로 형식 결정) |

옵션

- `--force`: 이미 있는 파일을 덮어쓴다. 없으면 덮어쓰기 대신 오류를 내고 멈춘다.
- `--permanent`: `rm`에서 휴지통을 거치지 않고 영구 삭제한다.
- `--dry-run`: 바뀔 내용만 `[미리보기]`를 붙여 출력하고 실제로는 건드리지 않는다.

모르는 옵션은 아무것도 실행하지 않고 오류를 낸다. `-`로 시작하는 파일은 `.\-이름`처럼 쓴다. `write`, `append`의 내용은 `-`로 시작해도 된다.

## 안전 장치

- 삭제는 기본적으로 휴지통으로 보내므로 되돌릴 수 있다.
- 쓰기·이름 변경·이동·복사·압축은 대상이 이미 있으면 `--force` 없이는 덮어쓰지 않는다.
- 다른 드라이브로 옮길 때는 복사가 끝난 뒤에 원본을 지운다.
- `--dry-run`은 실제 실행과 같은 검사(없는 경로, 덮어쓰기 충돌 등)를 해서 실패할 작업을 미리 알려 준다. 다만 권한, 디스크 공간, 파일 잠금 오류는 실제로 실행해야 알 수 있다.
